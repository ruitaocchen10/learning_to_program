C# vs. .NET

- C# is the language, .NET is the framework

C/C++ compiled code into 8086 architecture, but didn't compile into other hardwares
Java and C# is translated to bytecode --> intermediate language code.
Common Language Runtime (CLR) translates the IL code into the machine code (Just-in Time compilation) - as long as a machine has CLR, it can run the app

Namespaces - contains related classes
Assembly - contains related namespaces
